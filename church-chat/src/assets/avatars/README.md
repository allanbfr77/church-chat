# Avatares (cartoons) do chat

Coloque aqui as imagens que as pessoas poderão escolher na tela de login.

- Formatos aceitos: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`
- Use imagens quadradas (ideal 256x256 px ou mais) e leves (menos de 200 KB cada).
- O nome do arquivo é o identificador do avatar. **Não renomeie nem apague** um arquivo
  que já esteja em uso: mensagens antigas guardam esse nome.
- Todas as imagens desta pasta aparecem automaticamente na tela de login, em ordem
  alfabética. Para controlar a ordem, use prefixos: `01-leao.png`, `02-ovelha.png`...
- Não é possível criar avatares pelo app; só adicionando arquivos aqui e publicando.
